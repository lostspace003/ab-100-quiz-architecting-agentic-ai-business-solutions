KKey concepts

Non-determinism
Same input may produce variations — test quality distributions, not exact-match.
Validation criteria
Accuracy on holdout · robustness on adversarial inputs · fairness across slices · latency · cost.
Prompt validation
Checking prompts for clarity, context, examples, format, audience — best practice review.
End-to-end test
Cross-app scenarios across Dynamics 365 Sales / Service / CX — focus on hand-offs.
Adversarial testing
Probes for hallucination, bias, PII leakage, jailbreaks — required pre-launch.
Continuous regression
Tests run on every prompt, topic, knowledge-source, or model change.

CCheat sheet — when…then

When testing AI → measure ranges and quality, not exact equality.
When validating a custom model → use accuracy + robustness + fairness + latency.
When testing topics → cover happy + edge + fallback + recovery.
When tests are slow → use Copilot to draft test cases; humans curate adversarial ones.
When pre-launch → always run RAI tests for hallucination / bias / PII / jailbreak.
